# Bunlet — 视觉语言与设计系统

> 这份文档是设计决策的单一信源。所有 UI 迭代、AI 辅助设计、新增组件，均以此为基准。

---

## 一、设计哲学

### 核心定位

**草木疗愈系**——不是医疗工具，不是数据仪表盘，是一个了解你身体的陪伴者。

### 三条设计原则


| 原则      | 含义          | 反面（禁止）     |
| ------- | ----------- | ---------- |
| 有机 > 几何 | 圆润、自然、流动    | 方角、硬线、机械感  |
| 温暖 > 理性 | 奶油色调、植物意象   | 高对比冷色、科技蓝  |
| 陪伴 > 诊断 | 建议式语气、鼓励性表达 | 评分、异常标红、警告 |

## 二、色彩系统

### 基础色板


| Token 名称               | Hex       | 用途              |
| ---------------------- | --------- | --------------- |
| `color.bg.base`        | `#F9F0E9` | 全局背景、主底色        |
| `color.green.primary`  | `#76AB4A` | 卵泡期相位、运动图标、积极状态 |
| `color.purple.primary` | `#A8659F` | 黄体期相位、AI 助手标签   |
| `color.yellow.primary` | `#D7D04B` | 排卵期相位、节气季节标签    |
| `color.pink.primary`   | `#E98AB8` | 经期相位、主品牌强调色     |
| `color.text.primary`   | `#2D2D2D` | 正文、标题           |
| `color.text.secondary` | `#7A7A7A` | 副标题、描述、元信息      |
| `color.text.hint`      | `#AAAAAA` | 占位符、禁用状态        |
| `color.surface.card`   | `#FFFFFF` | 卡片背景（带轻微投影）     |
| `color.border.subtle`  | `#EDE4DC` | 分隔线、卡片边框        |


### 周期相位色对应

```
经期       → color.pink.primary    #E98AB8
卵泡期     → color.green.primary   #76AB4A
排卵期     → color.yellow.primary  #D7D04B
黄体期     → color.purple.primary  #A8659F
```

### 使用约束

- 禁止使用纯黑 `#000000` 作为文字色，用 `#2D2D2D`
- 禁止使用饱和度 >70% 的颜色作为大面积填充
- 背景只用 `color.bg.base`，不引入其他底色

## 三、字体系统

平台字体：iOS 系统默认 **SF Pro**（中文回落 PingFang SC）。不引入自定义字体。

### 字阶


| 角色             | 字号   | 字重             | 行高  | 使用场景        |
| -------------- | ---- | -------------- | --- | ----------- |
| `type.display` | 28pt | Bold (700)     | 1.2 | 节气名称、页面大标题  |
| `type.title`   | 20pt | Semibold (600) | 1.3 | 卡片标题、模块标题   |
| `type.body`    | 15pt | Regular (400)  | 1.6 | 正文描述、建议内容   |
| `type.label`   | 13pt | Medium (500)   | 1.4 | 数据标签、Tab 文字 |
| `type.caption` | 11pt | Regular (400)  | 1.4 | 元信息、辅助说明    |


### 约束

- 单页不超过 3 个字阶
- 禁止斜体
- 节气名称固定用 `type.display`，不因内容长度缩小

## 四、间距与圆角

### 间距系统（8pt 基准格）

```
space.xs   = 4pt
space.sm   = 8pt
space.md   = 16pt
space.lg   = 24pt
space.xl   = 32pt
space.xxl  = 48pt
```

- 卡片内边距：`space.md`（16pt）
- 卡片间距：`space.md`（16pt）
- 页面左右边距：`space.md`（16pt）
- 图标与文字间距：`space.sm`（8pt）

### 圆角

```
radius.sm  = 8pt    （小组件、标签）
radius.md  = 16pt   （卡片、模态框）
radius.lg  = 24pt   （底部 Sheet）
radius.full = 9999pt （圆形头像、药丸形按钮）
```

## 五、核心组件

### 5.1 健康数据栏（HealthBar）

位于页面顶部，横排展示当前关键指标。

**布局：** 等宽四格，图标 + 数值 + 趋势箭头（↑↓）  
**数据项：** HRV（心形）、日照（太阳）、运动时长（跑步）、步数（行走）  
**无数据时：** 显示 `--`，不隐藏格子  
**禁止：** 超过 4 个指标、添加标题标签

---

### 5.2 节气卡片（SolarTermCard）

**结构（从上到下）：**

1. 季节标签 pill（春 / 夏 / 秋 / 冬）— 右对齐
2. 节气名称 `type.display`
3. 节气描述一句话 `type.body`
4. 养生建议一句话 `type.body`
5. 底部：下一节气名称（左）+ 倒计时天数（右）

**颜色映射：**

```
春 → color.green.primary
夏 → color.yellow.primary
秋 → color.pink.primary
冬 → color.purple.primary
```

---

### 5.3 周期环（CycleRing）

页面核心视觉元素。

**规格：**

- 环形进度图，外径约 200pt，线宽约 20pt
- 四色分段，按实际周期天数比例分配
- 中心：当前相位 emoji + 相位名称 `type.label` + 天数 `type.caption`
- 环下方：当前相位描述，2–3 句，`type.body`，居中对齐

**约束：**

- 数据不足时显示灰色占位环，不猜测相位
- 禁止在环上叠加文字标注

---

### 5.4 建议卡片（AdviceCard）

**结构：**

- 左侧：维度图标（emoji 或线性图标）
- 标题：维度名称 `type.title`
- 内容：建议摘要 2–4 行 `type.body`
- 可展开查看完整内容

**维度图标对应：**

```
饮食   🍽
运动   🏃
睡眠   🌙
正念   🧘
恢复   💗
情绪   ☁️
节气   🌿
```

---

### 5.5 底部导航栏（TabBar）

固定两项，不扩展：


| Tab   | 图标   | 标签    |
| ----- | ---- | ----- |
| 主页    | 花朵图标 | 小花园   |
| AI 对话 | 星形图标 | AI 助手 |


**约束：** 禁止增加第三个 Tab，功能通过页面内模块扩展。

## 六、图标与插画

### 图标风格

- 线性图标为主，圆角描边
- 描边宽度：1.5pt
- 尺寸：24×24pt（导航）/ 16×16pt（行内）

### 植物插画系统

Logo 和装饰元素使用**牡丹花**作为核心意象，延伸原则：

- 只用植物 / 自然意象（花、叶、月、星）
- 禁止使用科技类图形（电路、芯片、数据流）
- 插画色彩取自品牌色板，不引入新颜色

---

## 七、交互与动效

- **过渡时长：** 200–300ms
- **缓动：** ease-in-out，避免线性动画
- **加载状态：** 骨架屏，背景色 `color.border.subtle`，禁用 spinner（太机械）
- **反馈：** 轻触觉反馈（haptic light）用于确认操作；禁止用于滚动

---

## 八、语气与文案规范

### 语气词汇表


| 允许             | 禁止        |
| -------------- | --------- |
| 可以试试 / 建议 / 或许 | 你必须 / 你应该 |
| 这个阶段通常…        | 你的身体出现了异常 |
| 注意保暖休息         | 检测到风险     |
| 身体处于恢复期        | 健康评分：低    |


### AI 助手人设

- 像一个了解你身体的朋友，不是医生，不是教练
- 说话有温度，不说教
- 不确定时说"暂时没有足够数据"，不猜测

---

## 九、禁止事项汇总

❌ 红色 / 橙色警告样式  
❌ 任何形式的健康评分或异常标签  
❌ 饱和度 >70% 的大面积颜色  
❌ 纯黑文字  
❌ 超过两层的导航嵌套  
❌ 自定义字体  
❌ 科技感图形和冷色系配色
